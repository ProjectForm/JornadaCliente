03 O problema

Uma regra de negócio, mil planilhas de distância.

Uma organização com múltiplos gestores de carteira precisa saber, a cada atualização da base de atendimentos, quais clientes já cumpriram a regra de negócio de "conclusão" — e quais teriam cumprido, se não fosse um lançamento inválido por erro de digitação ou integração. Esta é a mesma lógica resolvida com SQL + Python em vez de fórmulas de planilha, com um CLI para os gestores incluirem/editarem clientes com permissão por vertical, e um relatório Power BI para a visualização final.

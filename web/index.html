Painel de Acompanhamento de Carteira

Codigo no GitHub Simular inclusao Ver no Power BI
100% dados sinteticos — gerados por script (seed fixa), sem qualquer vinculo com clientes, empresas ou dados reais. Reconstrucao publica de um sistema de acompanhamento de carteira desenvolvido originalmente em Excel/VBA.

Uma organizacao com multiplos gestores de carteira precisa saber, a cada atualizacao da base de atendimentos, quais clientes ja cumpriram a regra de negocio de "conclusao" — e quais teriam cumprido, se nao fosse um lancamento invalido por erro de digitacao/integracao. Esta e a mesma logica de negocio resolvida com SQL + Python em vez de formulas de planilha, com um CLI para os gestores incluirem/editarem clientes com permissao por vertical, e um relatorio Power BI para a visualizacao final.
